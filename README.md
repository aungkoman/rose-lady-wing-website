## Prompt by GPT

```
Create a single HTML file (no external libraries, only HTML, CSS, and JavaScript) for a landing page of a women's clothing e-commerce mobile app called "Rose Lady Wings".

The page should be visually attractive, elegant, and feminine, using a fancy and modern tone.

Content to include:
A hero section with the app name "Rose Lady Wings", tagline: “Fashion with Grace & Wings”, and a brief description about the app helping women shop stylish clothing easily.

Two download buttons: “Download for Android” and “Download for iOS” (use icons or button styles to make them appealing).

A screenshot image placeholder or a mockup phone showing the app interface.

A features section listing key benefits (e.g., curated styles, free shipping, 24/7 support).

Testimonial section with 1–2 positive reviews.

A footer with minimal links like "Privacy Policy" and "Contact".

Technical Requirements:
Use inline CSS or internal <style> tag.

Include basic JavaScript for button click interaction (e.g., alert('Redirecting to app store...')).

Make it responsive for both desktop and mobile view.

Use soft pink, rose gold, and white tones to match the feminine brand identity.

No external libraries or frameworks (no Bootstrap, no jQuery).

Make sure the overall page feels premium, smooth, and encourages users to download the app.
```
